ApacheBench 2.3 against XAMPP Apache 2.4.58 (Win64) + mod_php 8.2.12, opcache disabled (XAMPP default).
Client and server on the same machine: Intel Core i7-7700HQ (4 cores / 8 threads, 2.8 GHz), 16 GB RAM, Windows 10 Pro 19045.
Each URL: warm-up of 300 requests, then `ab -n 2000 -c 10 -s 10`.
Starter app: veyrophp-app with APP_DEBUG=true, SQLite configured but not used by these routes, profiling disabled.
The baseline is a temporary public/__bench_baseline.php containing `<?php echo "Hello";` (deleted after the run).

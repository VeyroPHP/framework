# VeyroPHP brand assets

| File | Use |
| --- | --- |
| `veyrophp-icon.png` (1024×1024, transparent corners) | App icon, favicon source, social avatars |
| `veyrophp-logo-dark.png` (1000 wide) | Logo with wordmark and "Modern • Fast • Flexible", for dark backgrounds and the README |
| `veyrophp-logo-dark-480.png` | The same, smaller |

- **Starter favicons:** the starter application's `public/favicon.ico` (16, 32 and 48 px), `icon-512.png`, `apple-touch-icon.png` and `veyrophp-mark.png` are made from `veyrophp-icon.png`.
- **The logo is designed for dark backgrounds.** On light backgrounds, use the icon alone.
- **Release archives:** these files are not part of the framework's Composer archive (`archive.exclude`).
